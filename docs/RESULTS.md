# Monte Carlo Results

Generated by `ResultsReportTests` on 2026-09-28 with 200 paired trials per scenario, base seed 20260928, γ = 0.01, k = 1.0, rolling horizon 300 steps. The fixed-spread control is matched to the A-S spread at zero inventory using σ from a pilot run. All P&L in dollars on a $100.00 instrument with 1¢ ticks and 100-share lots. Session Sharpe = mean(ΔP&L)/sd(ΔP&L)·√steps (a per-session t-statistic, not annualised). Markouts are ticks per lot at 50 steps; negative = price moved against the fill.

These are simulation results under stated assumptions. They are not evidence of real-market profitability.
